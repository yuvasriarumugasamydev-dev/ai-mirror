## 🚀 SETUP IN 3 SIMPLE STEPS:

### STEP 1: Get ngrok Token (2 minutes)
1. Go to: https://ngrok.com/ → Sign up FREE
2. Get token: https://dashboard.ngrok.com/get-started/your-authtoken
3. Copy and save it ✅

### STEP 2: Run Colab Notebook (3 minutes)
1. Open: https://colab.research.google.com/
2. Upload file: `Colab_AI_Mirror_Backend.ipynb`
3. Enable GPU: Runtime → Change runtime → T4 GPU
4. Paste your ngrok token in the code
5. Click: Runtime → Run all
6. **Wait 2-3 minutes...**
7. Copy the ngrok URL shown (like: `https://xxxx.ngrok-free.app`) ✅

### STEP 3: Connect to Your App (1 minute)
1. Open: `server\.env`
2. Add these lines:
   ```env
   COLAB_BACKEND_URL=https://xxxx.ngrok-free.app
   AI_PROVIDER=colab
   ```
   (Use YOUR URL from Step 2)
3. Restart server: `npm run dev`
4. **DONE!** 🎉
